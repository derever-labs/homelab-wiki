# Medien

Dieses Kapitel bündelt den Media Stack: Jellyfin serviert die Mediathek, der Arr-Stack und die Content Pipeline automatisieren die Beschaffung, Jellyseerr nimmt Wünsche entgegen. Dazu kommen AudioBookShelf für Hörbücher und ergänzende Hilfstools.

## Systeme

- [Jellyfin](./jellyfin/) -- Media Server
- [Arr-Stack](./arr-stack/) -- Sonarr, Radarr, Prowlarr, SABnzbd
- [Jellyseerr](./jellyseerr.md) -- Media Requests
- [Content Pipeline](./content-pipeline/) -- Download-Automatisierung mit Batch Jobs und Telegram-Steuerung
- [AudioBookShelf](./audiobookshelf.md) -- Hörbücher und E-Books
- [Media-Hilfstools](./media-tools.md) -- Jellystat, Handbrake, LazyLibrarian, Profilarr
